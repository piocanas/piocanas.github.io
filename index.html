Vulkan Renderer

A real-time Vulkan-based rasterization renderer implementing a full forward rendering pipeline for a textured 3D scene. The project covers swapchain setup, synchronization, indexed mesh rendering, mipmapped texture sampling, and a first-person camera system for real-time navigation. It extends into physically based rendering using a microfacet BRDF (Beckmann NDF), alongside multiple debug visualization modes for mip levels, depth, and derivative analysis. Additional features include alpha-masked foliage rendering and a render-to-texture post-processing pass implementing a mosaic pixelation effect.

Physically Based Ray Tracer

Implemented a C++ ray tracer featuring geometric ray-triangle intersections, barycentric interpolation, Blinn-Phong shading, hard and soft shadows, recursive reflections, refraction, Fresnel effects, Monte Carlo path tracing, area light sampling, anti-aliasing, coloured transparency using Beer-Lambert absorption, and refractive caustics.

Animation and Physics Engine

A real-time OpenGL animation and physics simulation system featuring BVH-driven skeletal animation with hierarchical joint rendering, runtime blending between rest and run cycles, and forward motion with terrain-constrained height adjustment. It also includes a simple physics module with gravity-based bouncing spheres, elastic collisions, and character interaction via spherical collision approximation, extended to support uneven terrain using height sampling across multiple switchable landscapes.

Mesh Processing & Topology Analysis

Developed a C++ geometry-processing pipeline capable of constructing directed-edge meshes, detecting manifold topology errors, repairing mesh holes, computing surface genus using Euler characteristics, and performing curvature-based mesh simplification.
